PetCare Hub – Online Pet Marketplace and Veterinary Appointment System

PetCare Hub is a responsive web-based frontend application designed to help pet owners and pet lovers easily browse pets, purchase pet products, and book veterinary appointments through a simple and user-friendly interface.

---

🎯 Purpose of the Project

The purpose of this project is to create a modern and responsive frontend web application that demonstrates:

* Responsive web design
* Bootstrap 5 components
* Interactive user interfaces using JavaScript
* Clean and consistent UI/UX design
* Multi-page website structure

---

✨ Features

🏠 Home Page

* Navigation bar
* Hero section
* Featured pets section
* Featured products section
* Footer with contact information

🐶 Pet Marketplace

* Browse available pets
* Search pets by name
* View pet details
* Buy Now button

🛍️ Product Marketplace

* Display pet products
* Product cards with images and prices
* Responsive product grid

👨‍⚕️ Veterinary Doctors

* Doctor profiles
* Experience and availability details
* Book Appointment button

📅 Appointment Booking

* Appointment booking form
* Client-side validation using JavaScript
* Success alert message
